## Tech Debt

### Phase 76 (pre-existing, not introduced by this milestone)

1. **Out-of-bounds restored column index** — `portal_lazy.js` only guards `NaN || < 0`, not `>= colCount`. When a stored column index exceeds the current column count, `loadColumn(outOfBoundsIndex)` marks a ghost column as loaded (empty queue, no AJAX). `portal_mobile_tabs.js` correctly falls back to column 0. No user-visible impact. Low priority.

2. **`$('.gadgets').sortable()` no mobile guard** — `_dashboard.html.erb` activates jQuery UI sortable on all `.gadgets` containers unconditionally. On mobile, sortable may interfere with touch interactions. Pre-existing; no Cucumber regression observed in 25 scenarios. Tracked for a future phase.
