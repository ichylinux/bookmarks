## Typography

| Role | Size | Weight | Line Height |
|------|------|--------|-------------|
| Body | 16px (desktop 14px base × scale; mobile 16px base × scale) | 400 | 1.6 |
| Label / small | 13px | 600 | 1.2 |
| Section heading (h2) | 20px (1rem + minor bump via browser default or explicit declaration) | 600 | 1.3 |
| Page title (h1) | 28px (browser default h1 inside `.landing-hero`; consistent with landing page) | 600 | 1.2 |

Notes:
- Base font size comes from `common.css.scss`: `--font-size-medium-baseline: 14px` desktop, `16px` mobile. Policy pages inherit this automatically via `application.html.erb` layout.
- Lang-switcher links: 13px / weight 600 — reuse `.landing-lang-link` exactly as on landing page.
- Body prose paragraphs: 16px / weight 400 / line-height 1.6 (matching `.landing-description`).
- Section headings: 20px / weight 600 / line-height 1.3 — new `.policy-section-heading` class.
- Page title (h1): 28px / weight 600 / line-height 1.2 — weight 600 provides sufficient visual dominance at this size.

Declared weights: 400 (body) and 600 (headings and labels). No other weights used in this phase.

Source: common.css.scss (body base), landing.css.scss (lang-link and description sizes).

## Page Layout

Both `/privacy` and `/terms` share the same layout structure:

```
application.html.erb
  └─ <main class="landing-page">          ← reuse existing class; max-width 960px, centered
       ├─ <div class="landing-lang-switcher">   ← locale switcher, flush right
       │    ├─ link "日本語"  → privacy_path(locale: 'ja')
       │    └─ link "English" → privacy_path(locale: 'en')
       ├─ <div class="policy-back-link">        ← new minimal class
       │    └─ link "← ホームに戻る" / "← Back to home" → root_path
       └─ <article class="policy-content">      ← new class; white card on #f7f9fc bg
            ├─ <h1>                             ← page title from YAML
            └─ <section> × N                   ← one per policy section
                 ├─ <h2 class="policy-section-heading">
                 └─ <p>                         ← prose from YAML
```

Widths, max-width, and centering: inherit from `.landing-page` (max-width 960px, margin auto). No new layout tokens needed.

## Copywriting Contract

This phase has no interactive CTA, no empty state, no error state, and no destructive actions. Policy pages are read-only content.

| Element | Japanese | English |
|---------|----------|---------|
| Privacy page title | プライバシーポリシー | Privacy Policy |
| Terms page title | 利用規約 | Terms of Service |
| Back to home link | ← ホームに戻る | ← Back to home |
| Lang switcher: Japanese | 日本語 | 日本語 |
| Lang switcher: English | English | English |

## Interaction Contract

| Interaction | Behavior |
|-------------|----------|
| Visit `/privacy` unauthenticated | Returns 200, renders privacy policy in current locale |
| Visit `/terms` unauthenticated | Returns 200, renders terms of service in current locale |
| Click "日本語" lang link | Navigates to same page with `?locale=ja`; active state applied |
| Click "English" lang link | Navigates to same page with `?locale=en`; active state applied |
| Click "← Back to home" | Navigates to `root_path` (no locale param — uses session/default) |
| Authenticated user visits | Page renders normally (no redirect); header shows authenticated state |

No JavaScript needed. No AJAX. Server-rendered only.

## Accessibility

- `<main>` landmark wrapping `.landing-page` content
- `<article>` for policy content block
- `<section>` per policy section with `<h2>` heading — correct heading hierarchy (h1 page title, h2 sections)
- Lang switcher links: descriptive text ("日本語", "English") — no aria-label needed
- Back link: descriptive text — no aria-label needed
- Active lang link: add `aria-current="true"` on the active locale link
- Color contrast: #2f6feb on #FFFFFF = 4.56:1 (AA for normal text at 13px bold — passes WCAG AA for large/bold text; acceptable)
- Color contrast: #333 on #f7f9fc = sufficient (dark on near-white)
