# Plan 115-01: Form Auth Data Layer

## Goal

Add `password_auth_enabled` boolean to `users` and implement the two-way flag lifecycle.

## Tasks

1. Migration: `add_column :users, :password_auth_enabled, :boolean, null: false, default: false`
2. `User#after_password_reset` private callback — sets flag true on password reset flow
3. `User#disconnect_form_auth!` — clears flag and randomizes encrypted_password
4. 5 Minitest cases in `test/models/user_password_auth_test.rb`

## Success Criteria

- `password_auth_enabled` column exists with correct constraints
- `after_password_reset` fires only on Devise password reset (not OAuth user creation, not other saves)
- `disconnect_form_auth!` sets flag false and prevents `valid_password?`
- All 5 Minitest cases pass
