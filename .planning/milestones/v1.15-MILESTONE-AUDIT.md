## PREFS-01 Gap — CSS Specificity Regression

### Root Cause

Phase 50 removed `.modern .preferences-table th { text-align: right }` from `themes/modern.css.scss`, claiming it was redundant because `common.css.scss` defines `.preferences-table th { text-align: right }`.

**This analysis was incorrect.** The existing rule `.modern table th { text-align: left }` (lines 96–101 of modern.css.scss) has specificity **(0,1,2)** — one class `.modern`, two elements `table th`. The base rule `.preferences-table th { text-align: right }` in `common.css.scss` has specificity **(0,1,1)** — one class, one element.

Since (0,1,2) > (0,1,1), the modern table rule overrides the base rule regardless of load order. The removed `.modern .preferences-table th` rule had specificity **(0,2,1)** — two classes, one element — which correctly beat the table rule and preserved right-alignment on the modern theme.

**Result:** After Phase 50, `th` labels in the preferences form are **left-aligned on the modern theme at desktop widths**. The Phase 50 SUMMARY claim of "no visual change" was incorrect.

**Tests pass because** the three PREFS-0x Minitest tests use `assert_select` for element presence only — they do not assert alignment. The `VisualQaConsistencyContractTest` asserts the removed rule stays absent, which now incorrectly guards against the fix.

### Fix Required

**Option A (recommended):** Restore the rule in `themes/modern.css.scss` and update `VisualQaConsistencyContractTest`:

```scss
// themes/modern.css.scss — add back:
.modern .preferences-table th {
  text-align: right;
}
```

Update `test/assets/visual_qa_consistency_contract_test.rb`:
- Change the `assert_no_match` test to `assert_match` with `text-align:\s*right` to make it a correctness guard rather than an absence guard.

**Option B:** Raise specificity in `common.css.scss` using a child-combinator chain:
```scss
table.preferences-table > tbody > tr > th { text-align: right; }  // specificity (0,1,3)
```
This beats `.modern table th` (0,1,2) without touching theme files.

**Scope:** 2–4 lines of CSS + 2 lines of test update.
