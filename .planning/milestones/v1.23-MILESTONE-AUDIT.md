1. Phase 75: `f.check_box :show_icons` in preferences form → `:show_icons` permitted in strong params → `@user.save!` persists to DB
2. Phase 73: `Preference#show_icons` column (boolean, NOT NULL, default true)
3. Phase 74: `WelcomeHelper#no_icons_class` reads `current_user.preference.show_icons` → returns `'no-icons'` when false
