    - The event binding is `$(document).on('click.visitedLinks', '.gadget ol li a[href]', function() { ... })`
      — `.visitedLinks` namespace allows future `.off('click.visitedLinks')` teardown without disturbing other click handlers
    - Inside the function callback (NOT an arrow function — `this` must resolve to the clicked DOM element):
        1. `var url = this.href.replace(/#.*$/, '');`
           — `this.href` is the browser-resolved absolute URL (includes protocol + host + path)
           — The regex `/#.*$/` strips from `#` to end, matching `VisitedLink.normalize_url` in Ruby
        2. `$(this).addClass('link--visited');`
           — Optimistic: fires synchronously BEFORE the network request
        3. `$.post('/visited_links', { url: url });`
           — Fire-and-forget: no `.done()`, no `.fail()`, no `.always()`
           — CSRF token is injected automatically by `rails-ujs` `$.ajaxPrefilter` (loaded before `require_tree .` in application.js)
    - NO `e.preventDefault()` — the click is not blocked; the link navigates normally
    - Prettier format: use two-space indentation, single quotes, no trailing semicolons on closing braces
  </behavior>
