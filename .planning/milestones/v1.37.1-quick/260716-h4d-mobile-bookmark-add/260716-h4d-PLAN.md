<objective>
On mobile, make adding a bookmark work the same way as adding a task: tapping the
gadget header reveals the 「追加」 add link, which opens the existing new-bookmark
dialog. Today the task gadget has this tap-to-reveal interaction but the bookmark
gadget does not — on a mobile viewport the bookmark add link is `opacity:0` +
`pointer-events:none` (base rule + `@media (hover: none)`), so it is unreachable.

This is a **parity** task: reuse the exact mechanism already built for the task
gadget (the `title--gadget-actions-visible` header class toggled by a header tap,
plus the mobile CSS reveal rules) — do NOT invent a new interaction.

Purpose: Mobile users can add bookmarks, closing the gap with the task gadget.
Output: Tap-to-reveal wired into `bookmark_gadget.js` + `welcome.css.scss`, guarded
by a source-contract unit test and a `@mobile_portal` Cucumber scenario.
</objective>
