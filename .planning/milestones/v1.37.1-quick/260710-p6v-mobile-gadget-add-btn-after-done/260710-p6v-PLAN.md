<objective>
モバイルでタスクを完了した後に、ガジェットヘッダへ「追加」ボタンが誤って表示され続ける不具合を修正する。

Purpose: モバイルでは「追加」ボタンはヘッダをタップした時だけ表示されるべきで、タスク完了直後には表示されてはいけない（デスクトップと同じ最終状態）。
Output: `todos.js` の一行修正、ソース契約テスト、モバイル E2E シナリオ。

## 根本原因

モバイルでは `.todo-gadget-new-link`（「追加」）は既定で `opacity:0 / pointer-events:none` で隠れており、ヘッダ（`.title--gadget-with-icon`）タップで付与される `.title--gadget-actions-visible` クラスがある時だけ表示される（`welcome.css.scss` の `@media (max-width: 767px)` ブロック）。

一括完了 `todos.delete_todos` の成功コールバックは `todos._updateCompleteGroup(ol)` を呼び、選択件数が 0 になると `$newLink.show()` で「追加」リンクを再表示する。この時ヘッダには `.title--gadget-actions-visible` が残ったままのため、CSS ルールで「追加」ボタンが可視化されてしまう。

デスクトップは `div.title:hover` によるホバー表示のみで、永続クラスを使わないため、完了後は正しく非表示のまま。よってデスクトップ側の修正は不要。

## 修正方針

`todos.delete_todos` の成功コールバックで、当該ガジェットのヘッダから `title--gadget-actions-visible` を除去する。これにより完了後は「追加」ボタンが隠れ、次回ヘッダをタップした時に再び表示される（期待挙動）。デスクトップではクラスが元々付与されないため no-op。
