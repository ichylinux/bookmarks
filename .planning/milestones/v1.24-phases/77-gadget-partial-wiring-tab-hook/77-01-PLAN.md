# Phase 77 Plan 01: Gadget Partial Wiring + Tab Hook

**Goal**: Wire all AJAX gadget partials to register with `portalLazy`; hook `activateColumn` to drain each column on first visit; mobile lazy loading live.

## Tasks

1. Fix `portal_lazy.js` — `register` must handle already-loaded columns (PTM fires ready callbacks before gadget partial callbacks; without this fix the initial-column check in `register` is bypassed and nothing loads)
2. Pass `column_index: i` local to each gadget render in `_portal_column_section.html.erb`
3. Wrap `$.get` in `_feed`, `_mastodon_account`, `_x_account`, `_calendar_gadget` with `window.portalLazy.register(columnIndex, fn)`
4. Add `window.portalLazy.loadColumn(index)` in `activateColumn()` mobile block in `portal_mobile_tabs.js`
5. Tri-suite verification
