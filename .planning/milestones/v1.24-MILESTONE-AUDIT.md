## Tech Debt

### TEST-02 Partial (Phase 78)

**Requirement:** "Existing @mobile_portal Cucumber scenarios pass; new scenario verifies that only the active column loads on page init and that switching to a new column triggers exactly one load"

**Delivered:** Existing `@mobile_portal` Cucumber scenarios pass ✅. Static source-level regex assertion added in `portal_mobile_tabs_js_contract_test.rb` asserting `window.portalLazy.loadColumn(index)` appears inside `activateColumn` function body.

**Missing:** A behavioral Cucumber E2E scenario verifying that on mobile page init, only the initial column's AJAX gadget requests fire (non-active columns remain silent), and that column switching triggers exactly one load per column.

**Risk:** Low — static contract tests lock the code structure; existing Cucumber scenarios cover column switching; coordinator logic manually verified.

**Resolution:** Add a `@mobile_lazy_init` Cucumber scenario in a future cleanup phase.

### Pre-existing Debt (Phase 76)

1. **Out-of-bounds restored column index** — `portal_lazy.js` guards `NaN || < 0` but not `>= colCount`. When stored index exceeds column count, `loadColumn` marks a ghost column loaded; no AJAX fires; `portal_mobile_tabs.js` falls back to column 0. No user-visible impact. Low priority.

2. **`$('.gadgets').sortable()` no mobile guard** — `_dashboard.html.erb` activates jQuery UI sortable unconditionally. Pre-existing; no Cucumber regression in 25 scenarios.

## Integration Verification

All cross-phase wiring confirmed by integration checker:

1. **Sprockets load order** — `portal_lazy.js` IIFE fires at parse time (before `portal_mobile_tabs.js`'s `$(document).ready`)
2. **column_index propagation** — `_portal_column_section.html.erb` passes `column_index: i` to all gadget renders
3. **4 AJAX partials wired** — `_feed`, `_mastodon_account`, `_x_account`, `_calendar_gadget` all use `portalLazy.register(column_index, fn)`
4. **activateColumn tab hook** — `portal_mobile_tabs.js` calls `window.portalLazy.loadColumn(index)` in all three activation paths (tab click, swipe, localStorage restore)
5. **Synchronous mark-before-fire** — `loadedColumns[index] = true` before the `fns` loop; `notesLoaded = true` before `$.get` in `notes_tabs.js`
6. **Register already-loaded fix** — `register()` checks `loadedColumns[columnIndex]` before push (PTM-fires-first ordering fix)
7. **Note gadget AJAX chain** — `notes_tabs.js` + `_dashboard.html.erb` both fire `$.get('/notes/gadget')` → `noteGadgetLoaded` event → `note_gadget.js` re-init
8. **Auth protection** — `NotesController#gadget` inherits `authenticate_user!`; unauthenticated redirect tested
