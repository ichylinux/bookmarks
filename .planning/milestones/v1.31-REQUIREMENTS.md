# Requirements Archive: v1.31 — X Account Manual Add (Non-Following)

**Archived:** 2026-05-22
**Milestone:** v1.31 — X Account Manual Add (Non-Following)
**Status:** ✅ All requirements delivered

## v1.31 Requirements

### Schema & Model (XMAN)

- [x] **XMAN-01**: `x_accounts` table gains `manually_added boolean NOT NULL DEFAULT false`; existing rows default to `false` via migration
- [x] **XMAN-02**: `refresh_cache_from_items!` soft-delete sweep skips rows where `manually_added: true`; covered by Minitest
- [x] **XMAN-03**: `XAccount` provides an `upsert_manual!` method that creates or restores a manually-added account (`manually_added: true`, `deleted: false`)

### X API Service (XSVC)

- [x] **XSVC-01**: `XClient#lookup_user_by_username(username:)` calls `GET /2/users/by/username/:username`, strips leading `@`, reuses existing Bearer token and `normalize_following_row`
- [x] **XSVC-02**: Response parser handles all error codes: 404/400 → `:not_found`, 403 → `:suspended`, 429 → `:rate_limited`, other → `:api_error`; stores API-returned `username` (not user input)

### Controller & Routes (XCTL)

- [x] **XCTL-01**: `POST /x_accounts/lookup_and_add` action looks up handle, upserts via `upsert_manual!`, instruments via `record_x_api_call`, responds with redirect + flash
- [x] **XCTL-02**: All 7 error states surface as localized flash alerts (ja/en): not found, already active, rate limited, suspended, blank input, network error, and successful add

### View & Locales (XVIEW)

- [x] **XVIEW-01**: Inline `form_with` on `/x_accounts` index: text input for handle (`@username`), submit button, no new JS
- [x] **XVIEW-02**: Each account card on `/x_accounts` shows a visual indicator (badge or label) when `manually_added: true`; bilingual ja/en label
- [x] **XVIEW-03**: Bilingual locale strings (ja/en) for all new flash messages and UI labels; i18n parity test passes

### Tests & Gate (XTEST)

- [x] **XTEST-01**: Minitest: model tests for `manually_added` flag behavior and refresh guard; service tests with WebMock stubs for new endpoint; controller integration tests for all error paths
- [x] **XTEST-02**: Cucumber E2E: happy path (add by handle → account appears → survives Refresh); not-found scenario; WebMock stub for `/2/users/by/username/`; tri-suite gate green
