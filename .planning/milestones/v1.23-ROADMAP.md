# Milestone v1.23: Icon Display Preference

**Status:** ✅ SHIPPED 2026-05-17
**Phases:** 73–75
**Total Plans:** 5

## Overview

Adds a per-user icon display preference that lets users opt out of icons across the authenticated UI. A boolean `show_icons` column (default: true) on `preferences` drives a `body.no-icons` CSS class that suppresses `.gadget-title-icon` and `.drawer-nav-icon` elements globally. The preference is toggled from `/preferences` with ja/en locale strings. Landing page icons are unaffected (unauthenticated surface, no preference context).

### Phase 74: CSS + View Layer

**Goal**: Users who have `show_icons: false` see no icons on gadget titles or the drawer navigation, with no change to the landing page
**Depends on**: Phase 73
**Requirements**: ICON-02, ICON-03
**Plans**: 2 plans

Plans:

- [x] 074-001: WelcomeHelper#no_icons_class + layout body class
- [x] 074-002: CSS hide rules under body.no-icons

**Details:**

- `WelcomeHelper#no_icons_class` returns `'no-icons'` when `current_user.preference.show_icons == false`, else `''`; guards `user_signed_in?` and nil preference
- Layout `<body>` tag: `[favorite_theme, font_size_class, no_icons_class].join(' ').strip`
- `common.css.scss`: `body.no-icons .gadget-title-icon { display: none !important }` and `body.no-icons .drawer-nav-icon { display: none !important }`
- `!important` required to override higher-specificity existing rules (e.g. `.modern .drawer nav a .drawer-nav-icon { display: inline-flex }`)
- CSS covers all authenticated pages via shared `_gadget_title_with_icon` partial (welcome gadgets, `/mastodon_accounts/show`, `/x_accounts/show`, `/feeds/show`)
- Unauthenticated landing page unaffected: `no_icons_class` guards `user_signed_in?` first

## Milestone Summary

**Key Decisions:**

- CSS `body.no-icons` class pattern (same as `body.modern` for theme) — no partial changes needed; single CSS rule covers all authenticated pages
- `!important` on hide rules — necessary to override inline-flex rules from theme-scoped selectors
- Landing page icons deliberately unaffected — unauthenticated surface has no preference context; requirement explicitly out of scope
- `_gadget_title_with_icon` shared partial as the single coverage point for ICON-02 — all gadget header icons route through this partial
