  <action>
In `todos.toggle_highlight`, before the `$.ajax` call:

1. Capture `const $li = $btn.closest('li')` (already present).
2. Add `const ol = $li.closest('ol')`.
3. Add `const wasSelected = $li.hasClass('selected')`.

In the `success` callback, replace the current `$li.replaceWith(html)` with:

1. `const $newLi = $(html)`.
2. If `wasSelected`, call `$newLi.addClass('selected')` and `$newLi.find('span:first-child').addClass('selected')`.
3. `$li.replaceWith($newLi)`.
4. `todos._updateCompleteGroup(ol)`.

Do not change the highlight button click handler, selection click handler, PATCH URL, CSRF sourcing, or server partial. Do not add new globals or libraries. Prefer this preserve-and-reapply approach over refactoring to in-place DOM updates.
