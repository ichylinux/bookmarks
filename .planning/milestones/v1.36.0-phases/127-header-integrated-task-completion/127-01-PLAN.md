<objective>
Relocate the todo gadget's 完了 (complete) action from the standalone `.todo_actions` list row into the gadget header (the same `.title--gadget-with-icon` row as the 追加/new link), show a live selection count there, and reclaim the vertical space the old action row occupied. Selection behavior (row click → `span.selected` checkmark) and the bulk-complete backend (`POST /todos/delete`) are reused unchanged.

Purpose: Make multi-select task completion clearer and more space-efficient by consolidating the action and selection-count into the gadget header, per the v1.36.0 milestone goal.

Output: Updated `_todo_gadget.html.erb` header (complete group), new `welcome.todo_gadget.selected_count` locale keys (ja/en), refactored `welcome.css.scss` + cleaned `todos.css.scss`, removed `.todo_actions` partial, rewired `todos.js`, and updated dashboard test assertions so `bin/rails test` stays green.

Note: This phase ships NO new automated tests (that is Phase 128). It only updates the two existing `dashboard_test.rb` assertions that would otherwise break, to keep the suite green.

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| browser → Rails (POST /todos/delete) | User-supplied `todo_id[]` and CSRF token cross from the client into `TodosController#delete` |

This phase is a client-side relocation of an existing control. It introduces no new endpoint, no new request parameters beyond the `todo_id[]` already accepted by the existing action, and no authentication/authorization change. The CSRF token is still supplied — now read from `meta[name="csrf-token"]` (the same value the standalone action row previously embedded; already used by `todos.toggle_highlight`).
