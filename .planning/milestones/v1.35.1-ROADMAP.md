## Overview

Existing users can register a canonical Mastodon handle on `/preferences`. When signing in via Mastodon OAuth, if no `oauth_identities` row matches the composite uid, the app looks up an active user by matching the OAuth-verified username and instance against the stored handle — enabling sign-in to an existing account without creating a duplicate.
