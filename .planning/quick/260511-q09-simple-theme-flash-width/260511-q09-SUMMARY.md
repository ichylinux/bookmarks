# Quick Task 260511-q09: Simple Theme Flash Width Fix

## Problem

On the simple theme, flash notice/alert messages rendered in a narrow strip in the upper-left of the page (see `tmp/ss.png`) instead of spanning the full wrapper width like on modern/classic.

## Root Cause

`app/views/common/_menu.html.erb` renders `<div class="header">` only on the simple theme, inside `.wrapper`, before the flash-message div. The `.header` rule in `common.css.scss` set a fixed 20px height with a right-floated `.email` `<li>`, but did not establish a block formatting context. The inner `<ul class="navigation">` carried the default user-agent vertical margin (~16px), so the floated email overflowed below `.header`. The next sibling `<div class="flash-message">` is `display: flex`; a flex container's margin-box must avoid floats in its containing block, so it shrank to the left of the leaked float.

Modern and classic themes don't render `<div class="header">` inside `.wrapper`, so they never had the issue.

## Fix

Two-line change in `app/assets/stylesheets/common.css.scss`:

1. Add `display: flow-root;` on `.header` so it establishes a BFC and contains its floats.
2. Add `margin: 0;` to `ul.navigation` so the inner list height matches the 20px header.
