# Quick Task 260609-pvs: モバイルでのTODO強調表示

モバイルで操作する時は、どのように強調表示することが可能だろうか？

## 方針

デスクトップはホバーでボタン表示。モバイル（≤767px）ではホバー不可のため、強調ボタンを常時表示する（CSS のみ）。

## 検討した代替案

| 方式 | 却下理由 |
|------|----------|
| ロングプレス | ガジェット並べ替え（2秒長押し）と競合 |
| ダブルタップ | ノートガジェットはモバイル編集に使用、TODO は dblclick 編集と混同 |
| スワイプアクション | ポータル列スワイプと競合、実装コスト大 |

## Task

- `todos.css.scss`: `@media (max-width: 767px)` で `.todo-highlight-btn` を常時表示
