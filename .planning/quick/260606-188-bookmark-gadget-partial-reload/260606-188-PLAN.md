# Quick Task 260606-188: ブックマークガジェット部分リロード

**Description:** ブックマークをガジェットの追加ダイアログから登録後は画面全体をリロードせずにブックマークガジェットだけリロードしたい。

## Tasks

### Task 1: gadget エンドポイントと create の XHR 対応

**files:**
- `config/routes.rb`
- `app/controllers/bookmarks_controller.rb`
- `app/views/bookmarks/gadget.html.erb`

**action:**
- `GET /bookmarks/gadget` を追加（notes/calendars と同様、`layout: false` でガジェット partial を返す）
- `create` で `return_to=dashboard` かつ XHR の場合は `head :ok` を返し、バリデーション失敗時は 422 + エラーメッセージ

**verify:** `bin/rails test test/controllers/bookmarks_controller_test.rb`

**done:** gadget エンドポイントが 200 でガジェット HTML を返し、XHR create がリダイレクトせず 200 を返す

### Task 2: ダイアログフォームを AJAX 化しガジェットを部分更新

**files:**
- `app/views/welcome/_bookmark_gadget.html.erb`
- `app/assets/javascripts/bookmark_gadget.js`

**action:**
- ダイアログフォームに `remote: true` と `data-gadget-url` を付与
- `ajax:success` でダイアログを閉じてフォームをリセットし、`$.get(gadget_url)` で `#bookmark_gadget` と `#bookmark-new-dialog` を差し替え
- フォルダ開閉ハンドラをイベント委譲に変更し、リロード後も localStorage の展開状態を復元

**verify:** `bin/rails test test/controllers/welcome_controller/dashboard_test.rb`

**done:** 登録後にページ全体をリロードせずガジェットだけ更新される
