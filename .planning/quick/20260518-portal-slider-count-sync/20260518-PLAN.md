# Quick Task 20260518: ポータル列数変更時のスライダー数連動修正

## Objective

列数ドロップダウン変更時に `rebuildControls()` が `root.querySelector('[data-portal-width-row-template]')` で `null` を返してしまいスライダーを再構築しない。

`<template data-portal-width-row-template>` が `data-portal-column-widths-root` の **外側** に配置されているのが原因。

## Root Cause

`_portal_column_widths.html.erb` の構造:

```
</div>   ← data-portal-column-widths-root の閉じタグ (line 30)
<template data-portal-width-row-template>  ← rootの外 (line 31)
```

`rebuildControls` は `root.querySelector('[data-portal-width-row-template]')` で検索するため、root外のテンプレートを見つけられず即 return する。

## Fix

`<template>` 要素を `data-portal-column-widths-root` の内側に移動する。

**File:** `app/views/preferences/_portal_column_widths.html.erb`

- `</div>` (root close) の前に `<template>` ブロックを配置する

## Tasks

- File: `app/views/preferences/_portal_column_widths.html.erb`
