# Quick 260712-j75 Plan 01: CSS Hardening for Mobile "追加" Button Visibility — Summary

## One-liner

`@media (max-width: 767px)` に specificity (0,4,0) の `opacity: 0` 規則を追加し、ヘッドレス Chrome の sticky `:hover` が「追加」を表示してしまう間欠失敗リスクを根絶。

## What Was Built

`features/02.タスク.feature:31`「モバイルでタスクを完了した直後は『追加』ボタンが表示されない」の潜在的間欠失敗を防御的 CSS ハードニングで解消した。

### 変更内容

**`app/assets/stylesheets/welcome.css.scss`**

`@media (max-width: 767px)` ブロック内の既存 2 規則の間に新規規則を 1 つ追加:

```scss
// Specificity (0,4,0) — overrides :hover rule (0,3,1)
.gadget.todo .title--gadget-with-icon .todo-gadget-new-link {
  opacity: 0;
}
```

詳細度の関係:
| セレクタ | 詳細度 | 効果 |
|----------|--------|------|
| `div.title:hover .todo-gadget-new-link` | (0,3,1) | hover 時に表示（デスクトップ向け） |
| `.gadget.todo .title--gadget-with-icon .todo-gadget-new-link` | (0,4,0) | **モバイルで上書き → 常に opacity:0** |
| `.gadget.todo .title--gadget-with-icon.title--gadget-actions-visible .todo-gadget-new-link` | (0,5,0) | タップ表示クラスがある場合のみ opacity:1 |

**`test/assets/todo_gadget_mobile_css_contract_test.rb`**

新規テスト 1 件追加（6件→合計6件、assertions 14→17）:
- `test 'welcome.css.scss hides new-link on mobile independent of :hover (QUICK-MOB-ADDBTN-02)'`
- `@media (max-width: 767px)` 内で `.gadget.todo .title--gadget-with-icon .todo-gadget-new-link` に `opacity: 0` が設定されていることを `assert_match` で検証
