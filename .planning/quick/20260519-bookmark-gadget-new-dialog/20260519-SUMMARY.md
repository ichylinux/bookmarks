# Quick Task: new bookmark can be added in a dialog on dashboard page

## What was done

Added a hover-visible "new" link to the bookmark gadget header and a native `<dialog>` for creating bookmarks without leaving the dashboard.

### Changes

- **`app/views/welcome/_bookmark_gadget.html.erb`** — Inlined the gadget title HTML (previously used shared partial) to add `.bookmark-gadget-new-link` on the right side of the flex header. Added `<dialog id="bookmark-new-dialog">` with a full bookmark creation form (URL, title, parent folder).
- **`app/assets/stylesheets/welcome.css.scss`** — Added `.bookmark-gadget-new-link` styles (hidden by default, visible on `.title:hover`; `margin-left: auto` pushes it right). Added `.bookmark-new-dialog` block with header, form field, and backdrop styles.
- **`app/assets/javascripts/bookmark_gadget.js`** — Added mousedown `stopPropagation` on the link (prevents sortable drag), click handler to call `dialog.showModal()`, close button handler, and click-outside-to-close.
- **`app/controllers/bookmarks_controller.rb`** — In `create`, if `params[:return_to] == 'dashboard'` redirect to `root_path` instead of bookmarks index.
- **`config/locales/ja.yml` / `en.yml`** — Added `welcome.bookmark_gadget.*` keys: `new_link`, `new_link_aria_label`, `dialog_title`, `dialog_close_aria_label`.
- **`test/controllers/welcome_controller/dashboard_test.rb`** — Updated two assertions from `.title` to `.gadget-title-text` (title now contains the link text in addition to gadget name).
