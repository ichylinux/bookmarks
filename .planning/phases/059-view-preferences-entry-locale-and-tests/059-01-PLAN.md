## Trust Boundaries

| Boundary | Description | Data crossing |
|----------|-------------|----------------|
| Browser (authenticated session) → Rails | Signed-in user only; CSRF on POST | Session cookie, form params (`email_registration[email]`) |

| Locale YAML → Views | Static copy for form chrome and flashes | Non-user-controlled strings |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-59-01 | Spoofing | `users/email_registration` | mitigate | `ApplicationController` enforces Devise `authenticate_user!`; actions use `current_user` only |
| T-59-02 | Elevation of privilege | Dummy-only surface | mitigate | `before_action :require_dummy_email` redirects when `current_user.has_valid_email?` |
| T-59-03 | Tampering | Email uniqueness / race | mitigate | DB uniqueness + `rescue ActiveRecord::RecordNotUnique` → `:taken` error path |
| T-59-04 | Information disclosure | Errors and flash | mitigate | Standard model errors + fixed locale keys for success; ERB `<%= message %>` escapes `full_messages` |
| T-59-05 | Tampering | Mass assignment | mitigate | `email_registration_params` — `require(:email_registration).permit(:email)` only |
| T-59-06 | Tampering | CSRF on POST | mitigate | `form_with` / Rails authenticity token on `create` |
</threat_model>
