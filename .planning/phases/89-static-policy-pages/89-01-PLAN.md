<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| unauthenticated HTTP → PagesController | Any visitor can reach /privacy and /terms without a session |
| locale param → session write | ?locale=ja/en writes to session[:guest_locale] via Localization concern |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-89-01 | Elevation of Privilege | PagesController skip_before_action | mitigate | skip is intentional and scoped to PagesController only; ApplicationController still enforces auth for all other controllers; no user data is exposed on these pages |
| T-89-02 | Tampering | locale param (session write) | accept | Localization concern validates locale against Preference::SUPPORTED_LOCALES allowlist; non-matching values are silently ignored; no sensitive data in guest_session_locale |
| T-89-03 | Tampering | YAML body text rendered via t() | accept | Rails t() HTML-escapes by default; simple_format (used in views) auto-escapes; raw() is not used; YAML content is developer-controlled, not user input |
| T-89-SC | Tampering | npm/pip/cargo installs | accept | No package manager installs in this phase — package legitimacy gate not applicable |
</threat_model>
