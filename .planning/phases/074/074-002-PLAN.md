# Plan 074-002: CSS — hide icons under body.no-icons

## Objective

Add two CSS rules to `common.css.scss` that hide `.gadget-title-icon` and `.drawer-nav-icon` elements when `body.no-icons` is present. Landing page icons (not under these classes on the authenticated pages) are unaffected.

## Tasks

### Task 1: Add no-icons CSS rules to common.css.scss

<read_first>
- app/assets/stylesheets/common.css.scss (full file — understand existing structure and find appropriate insertion point)
- app/views/common/_gadget_title_with_icon.html.erb (confirm .gadget-title-icon selector)
- app/views/common/_drawer_nav_link.html.erb (confirm .drawer-nav-icon selector)
</read_first>

<action>
Append to the end of `app/assets/stylesheets/common.css.scss`:

```scss
// Icon display preference
body.no-icons .gadget-title-icon {
  display: none !important;
}

body.no-icons .drawer-nav-icon {
  display: none !important;
}
```

Both rules use `!important` because existing rules (e.g., `.modern .drawer nav a .drawer-nav-icon { display: inline-flex }` and `div.title.title--gadget-with-icon .gadget-title-icon { display: inline-flex }`) have higher specificity (0,3,2 and 0,3,1 respectively) and would otherwise override the hide rules.
</action>

<acceptance_criteria>
- `common.css.scss` contains `body.no-icons .gadget-title-icon { display: none !important; }`
- `common.css.scss` contains `body.no-icons .drawer-nav-icon { display: none !important; }`
- `yarn run lint` passes (no SCSS lint errors)
- `bin/rails assets:precompile` exits 0 (no Sass compile errors)
</acceptance_criteria>
