# Plan 074-001: WelcomeHelper — no_icons_class + layout body class update

## Objective

Add `no_icons_class` helper to `WelcomeHelper` that returns `'no-icons'` when the authenticated user has `show_icons == false`. Update the application layout body tag to include this class alongside `favorite_theme` and `font_size_class`.

## Tasks

### Task 1: Add no_icons_class to WelcomeHelper

<read_first>
- app/helpers/welcome_helper.rb (full file — understand pattern of favorite_theme and font_size_class)
</read_first>

<action>
In `app/helpers/welcome_helper.rb`, add method after `font_size_class`:

```ruby
def no_icons_class
  return '' unless user_signed_in?
  return '' unless current_user.preference.present?
  current_user.preference.show_icons == false ? 'no-icons' : ''
end
```

Method returns `'no-icons'` only when user is signed in, has a preference, and `show_icons` is explicitly `false`.
</action>

<acceptance_criteria>
- `app/helpers/welcome_helper.rb` contains `def no_icons_class`
- Method returns `''` when user is not signed in
- Method returns `''` when preference is nil or show_icons is true
- Method returns `'no-icons'` when `current_user.preference.show_icons == false`
</acceptance_criteria>

### Task 2: Update layout body tag to include no_icons_class

<read_first>
- app/views/layouts/application.html.erb (full file — see existing body class pattern on line 16)
</read_first>

<action>
Update `app/views/layouts/application.html.erb` line 16:

From:
```erb
  <body class="<%= [favorite_theme, font_size_class].join(' ') %>">
```

To:
```erb
  <body class="<%= [favorite_theme, font_size_class, no_icons_class].join(' ').strip %>">
```

`.strip` removes trailing whitespace when `no_icons_class` returns `''`.
</action>

<acceptance_criteria>
- `application.html.erb` body tag contains `no_icons_class` in the class array
- `.join(' ').strip` is used (prevents trailing space when no-icons class is absent)
- When `show_icons` is false, rendered HTML body tag contains class `no-icons`
- When `show_icons` is true, rendered HTML body tag does NOT contain `no-icons`
</acceptance_criteria>
