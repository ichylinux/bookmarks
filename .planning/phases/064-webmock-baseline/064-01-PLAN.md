      # frozen_string_literal: true

      require 'webmock/minitest'

      # Block all external HTTP in tests.
      # allow_localhost: true permits Capybara's embedded Puma server and Selenium
      # ChromeDriver (both on 127.0.0.1) so the Cucumber/browser suite is unaffected.
      # This covers localhost, 127.0.0.1, and ::1.
      WebMock.disable_net_connect!(allow_localhost: true)

    Key implementation notes:
    - Use `require 'webmock/minitest'` NOT `require 'webmock'` alone — the /minitest shim installs WebMock.enable! plus a Minitest::Test#teardown hook that calls WebMock.reset! after every test, preventing stub bleed between tests.
    - Use `allow_localhost: true` NOT a bare `WebMock.disable_net_connect!` — the bare form blocks 127.0.0.1 and crashes Selenium/Capybara browser tests immediately.
    - Do NOT use `require 'webmock/cucumber'` — this phase is wired through test/support/ which must serve Minitest first; Cucumber's After reset hook is Phase 66 scope.
    - Do NOT add a module wrapper around these calls — class_eval runs require at Kernel scope regardless, and a module wrapper would be inconsistent with other support files.
  </action>
