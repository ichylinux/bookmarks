# Phase 114-01: OAuth Identity Data Layer — Schema, Model, Wiring & Tests

## Objective

Create the `oauth_identities` table, the `OauthIdentity` model, wire all three provider branches in `User.from_omniauth` to upsert a row on every successful sign-in, add a backfill migration, and verify with Minitest.

## Must-Haves (Goal-Backward)

- `oauth_identities` table exists with unique index on `(user_id, provider)` and FK to `users`
- `OauthIdentity` model validates presence of `provider` and `uid`; validates uniqueness of `provider` scoped to `user_id`
- `User.from_omniauth` calls `OauthIdentity.upsert_for!` in all three provider branches (only when user is persisted)
- Backfill migration is idempotent (uses `insert_all` with `unique_by:`)
- Minitest covers: model validations, upsert for each provider (new user + existing user), backfill idempotency

<action>
Write `app/models/oauth_identity.rb`:

```
class OauthIdentity < ApplicationRecord
  belongs_to :user

  validates :provider, presence: true
  validates :uid, presence: true
  validates :provider, uniqueness: { scope: :user_id }

  def self.upsert_for!(user:, provider:, uid:)
    identity = find_or_create_by!(user_id: user.id, provider: provider.to_s)
    identity.update!(uid: uid.to_s)
    identity
  end
end
```
</action>

```ruby
class BackfillOauthIdentitiesFromUsers < ActiveRecord::Migration[8.1]
  def up
    rows = User.where.not(provider: nil).where.not(uid: nil).pluck(:id, :provider, :uid, :created_at)
    records = rows.map do |user_id, provider, uid, created_at|
      { user_id: user_id, provider: provider, uid: uid, created_at: created_at, updated_at: created_at }
    end
    return if records.empty?

    OauthIdentity.insert_all(records, unique_by: :index_oauth_identities_on_user_id_and_provider)
  end

  def down
    # Backfill is not reversible — manual cleanup required
  end
end
```
