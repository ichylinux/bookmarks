Run grep audit across all 9 non-theme SCSS files. Capture output as evidence.

```bash

  app/assets/stylesheets/bookmarks.css.scss \
  app/assets/stylesheets/calendars.css.scss \
  app/assets/stylesheets/common.css.scss \
  app/assets/stylesheets/devise.css.scss \
  app/assets/stylesheets/feeds.css.scss \
  app/assets/stylesheets/landing.css.scss \
```
