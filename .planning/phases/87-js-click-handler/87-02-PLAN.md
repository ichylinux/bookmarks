Navigation intercept technique (to be used in a step definition):
  # Adding a capture-phase listener that calls e.preventDefault() prevents the
  # browser from following the href while still allowing the click event to bubble
  # up to document where jQuery's delegated handler picks it up.
  # e.preventDefault() does NOT stop propagation — the jQuery handler WILL fire.
  page.execute_script(<<~JS)
    document.querySelectorAll('.gadget ol li a').forEach(function(a) {
      a.addEventListener('click', function(e) { e.preventDefault(); }, true);
    });
  JS
  # This must run AFTER the gadget content is AJAX-injected (anchors must exist in DOM).
  # Run it in its own step, after the step that asserts the gadget link is visible.
