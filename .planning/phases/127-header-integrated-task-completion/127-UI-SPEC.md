## Spacing Scale

The existing codebase does not enforce a strict 8-point scale globally; it uses contextual values. The following reflects the tokens actually observed in relevant files and maps them to the nearest conceptual scale slot. New additions in Phase 127 must use values from this set only.

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Gadget title padding (`padding: 4px`) |
| sm-alt | 6px | Header row gap (`gap: 6px` in `.title--gadget-with-icon`) — pre-existing exception |
| sm | 8px | General element spacing baseline |
| action-pad | 1px 4px (vertical/horizontal) | Link-button padding — matches `todo-gadget-new-link` (`padding: 1px 6px`) — use 1px 6px to match exactly |
| md | 16px | Default section spacing |

**Exceptions:**
- `gap: 6px` in `.title--gadget-with-icon` is a pre-existing value — do NOT change it to 8px.
- Link-button padding is `1px 6px` (not a clean multiple of 4); this is a pre-existing pattern from `.todo-gadget-new-link` that the new 完了 link must match exactly.
- Touch targets: no additional exception needed — the new 完了 link is a desktop-primary control; the mobile pattern (tap selection on `li`) is unchanged.

| Role | Size | Weight | Line Height | Notes |
|------|------|--------|-------------|-------|

| Selection count text | 0.78em (~11px) | 400 (normal) | 1.4 | Must match gadget action link size; sits inline with the 完了 link |

**Rule:** Phase 127 introduces no new font sizes. Four declared sizes above; two weights (400, 700).

## Color

The existing app uses a minimal, inherited color scheme. No custom CSS color variables are declared. Values below are extracted from `common.css.scss` and `welcome.css.scss`.

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | #FFFFFF | Body background, gadget surface |
| Secondary (30%) | rgba(0,0,0,0.20) | Gadget title bar background (renders as ~#CCCCCC on white) |
| Accent (10%) | currentColor (inherited browser link blue) | 完了 link border (`border: 1px solid currentColor`), new-link border — reserved for gadget header action links only |
| Destructive | not applicable | No destructive action in Phase 127 (completing a task is non-destructive; no delete confirmation) |

**Accent reserved for:** The `todo-gadget-new-link` and the new 完了 link (`.todo-gadget-complete-link`). No other elements may use the bordered link-button style.

**Visibility states (selection-driven, not hover-driven):**
- 完了 group (count + link) is hidden via `display:none` when 0 items are selected.
- 完了 group becomes visible when ≥1 item is selected — this is NOT tied to hover state.
- The existing `todo-gadget-new-link` opacity-on-hover rule is NOT applied to the 完了 group. The 完了 group appears/disappears based on selection count only.
- The new-link (`追加`) retains its existing hover-opacity behavior unchanged.

## Component Inventory

New components introduced in Phase 127 (no new JS libraries; all within `window.todos` namespace):

### `.todo-gadget-complete-group` (new HTML span)

**Element:** `<span class="todo-gadget-complete-group">`

**Location:** Inside `.title--gadget-with-icon`, after the existing `header_link` (the 追加 link). Passed via a new `complete_group:` local to `_gadget_title_with_icon.html.erb`, or bundled within the `header_link` block as a sibling — implementation choice for the executor, but the rendered output must be a flex-sibling of `.todo-gadget-new-link` within the header flex row.

**CSS:**
```scss
.todo-gadget-complete-group {
  display: none;          // JS toggles to flex or inline-flex when count > 0
  align-items: center;
  gap: 4px;               // xs token — gap between count text and 完了 link
  flex-shrink: 0;
}
```

**States:**
- `display: none` — 0 items selected (default, DOM present)
- `display: inline-flex` (or `flex`) — ≥1 item selected (JS managed)

### `.todo-gadget-selected-count` (new HTML span)

**Element:** `<span class="todo-gadget-selected-count">`

**Location:** First child inside `.todo-gadget-complete-group`, immediately left of the 完了 link.

**CSS:**
```scss
.todo-gadget-selected-count {
  font-size: 0.78em;
  font-weight: normal;
  line-height: 1.4;
  white-space: nowrap;
  color: inherit;
}
```

**Content:** Rendered via I18n interpolation — `t('welcome.todo_gadget.selected_count', count: N)`.

### `.todo-gadget-complete-link` (new `<a>` element)

**Element:** `<a class="todo-gadget-complete-link" href="<%= delete_todos_path %>" onclick="todos.delete_todos(this); return false;">`

**Location:** Second child inside `.todo-gadget-complete-group`, after the count text.

**CSS:** Must match `.todo-gadget-new-link` exactly. Add to the shared rule:
```scss
.bookmark-gadget-new-link,
.todo-gadget-new-link,
.todo-gadget-complete-link {
  // existing shared properties unchanged
  margin-left: 0;   // EXCEPTION: no auto margin — parent group handles right-alignment
  flex-shrink: 0;
  font-size: 0.78em;
  font-weight: normal;
  text-decoration: none;
  padding: 1px 6px;
  border-radius: 3px;
  border: 1px solid currentColor;
  line-height: 1.4;
  cursor: pointer;
  // NO opacity/transition — visibility is managed by parent .todo-gadget-complete-group display
}
```

**Note on `margin-left: auto`:** The existing `.todo-gadget-new-link` uses `margin-left: auto` to push itself to the far right of the flex header. The new 完了 link does NOT need `margin-left: auto` because the entire `.todo-gadget-complete-group` sits to the right of the 追加 link; the count+complete pair is a single container. The container itself is right-aligned naturally as the last flex child.

**CSRF:** Sourced from `$('meta[name="csrf-token"]').attr('content')` — not from `.todo_actions` (which is being removed). The `todos.delete_todos` function must be updated to use this source. The `data-authenticity_token` attribute on `.todo_actions` is no longer needed.

## Interaction States

This phase is primarily a JS visibility contract. The executor must implement the following state machine in `todos.js`:

| State | Trigger | Header shows | `.todo_actions` row |
|-------|---------|-------------|---------------------|
| **Zero selected** | Initial / all deselected | Icon + title + 追加 link (hover-opacity) | Removed from DOM entirely (LAY-01) |
| **One or more selected** | `click 'li span:first-child'` increments count | Icon + title + 追加 link + count text + 完了 link | Already removed |
| **Complete executed** | Click 完了 link → `todos.delete_todos` → POST /todos/delete | Count resets to 0 → group hides | Already removed |

**Selection toggle update (existing handler extension):**
The `click 'li span:first-child'` handler in `todos.init` must be extended to:
1. Count `ol.find('li.selected').length` after each toggle.
2. Update `.todo-gadget-selected-count` text: `t('welcome.todo_gadget.selected_count', count: N)`.
3. Toggle `.todo-gadget-complete-group` display: `display: none` when count === 0, `display: inline-flex` (or `flex`) when count > 0.

The selection guard in the existing handler (`if (!$(this).parent().is('.todo_actions'))`) must be updated: since `.todo_actions` no longer exists, this guard can be simplified or removed.

**`todos.new_todo` insertion point:**
Currently inserts after `.todo_actions`: `ol.find('.todo_actions').after(...)`. After `.todo_actions` removal this becomes: prepend to `<ol>` as first child — `ol.prepend('<li>' + html + '</li>')`.

**Empty guard:**
0-selection 完了 click is prevented by `display:none` (the link is not clickable). Additionally, `todos.delete_todos` must guard: if `params.todo_id.length === 0`, return early with no-op.

## CSS Cleanup

When removing `.todo_actions`, also clean up these selectors in `todos.css.scss` and `welcome.css.scss`:

| Selector | Action |
|----------|--------|
| `.todo_actions { min-height: 1.2em; a:visited { color: blue; } }` | Remove entirely |

| `li.highlighted:not(.todo_actions)` | Replace with `li.highlighted` |
| `li:not(.todo_actions):hover .todo-highlight-btn` | Replace with `li:hover .todo-highlight-btn` |
| `li:not(.todo_actions) .todo-highlight-btn` | Replace with `li .todo-highlight-btn` |
| `li:not(.todo_actions).todo-highlight-visible .todo-highlight-btn` | Replace with `li.todo-highlight-visible .todo-highlight-btn` |
| `&:not(.todo_actions):has(form.todo)` | Replace with `&:has(form.todo)` |
| `&:not(.todo_actions):not(:has(form.todo))` | Replace with `&:not(:has(form.todo))` |

In `todos.js`, remove all `.todo_actions` string references:
